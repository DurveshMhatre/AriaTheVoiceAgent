# Research ledger

Read date: 2026-10-27. Sources are official unless marked otherwise.

Voice-call repair recheck (no version changes): Groq's local-tool-calling guide requires complete streamed function calls and matching `tool_call_id` results. LiveKit's Sarvam STT guide documents provider-native VAD and no automatic realtime reconnection; its events reference distinguishes recoverable from terminal errors. The installed Agents/Sarvam 1.8.6 APIs confirm that reply generation still requires a non-null `llm` when overriding `llm_node`, `vad=None` disables implicit VAD, and session close completion must be awaited before text handover. Use one Brain-owned LLM route, explicit STT turn detection, no metered voice retries, and serialized room messages. Sources: https://console.groq.com/docs/tool-use/local-tool-calling ; https://docs.livekit.io/agents/models/stt/sarvam/ ; https://docs.livekit.io/reference/agents/events/ .
